# 路线图

## v0.1 公开文章到平台草稿

- [x] 初始化仓库、CLI、本地配置和测试入口。
- [x] 导入 Galley 公开文章并记录不可变快照。本地页面样本已验证。
- [x] 用本地 Galley 生产构建的公开页面确认公式、Mermaid、提示框、知识块和折叠内容，补充冷启动流式页面样本。
- [x] 新增素材、平台构建、审核和同步记录的数据表与迁移，验证旧工作区可升级。
- [x] 实现 `build`，生成两平台的 HTML、Markdown、素材清单和离线预览。
- [x] 静态化公式（MathJax + resvg）和 Mermaid（可选 Playwright），按输入缓存素材。
- [x] 实现 `preview`、`review`、`status`，测试正文、素材和封面改动后的审核失效。
- [x] 实现 `sync`、`resolve`。通过真实 Wechatsync CLI 预演，并用模拟扩展及测试覆盖成功、失败、`unknown` 和重复提交。
- [ ] 用线上公开文章和已登录账号核对公众号、头条草稿的正文、封面、摘要和回执。
- [x] 更新 Agent Skill，覆盖本地准备、预演和人工确认步骤。

架构细节见[架构](architecture.md)。
