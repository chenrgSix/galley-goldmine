# 路线图

## v0.1 公开文章到平台草稿

- [x] 初始化仓库、CLI、本地配置和测试入口。
- [x] 导入 Galley 公开文章并记录不可变快照。本地页面样本已验证。
- [ ] 用真实 Galley 文章确认公式、Mermaid、提示框、知识块和折叠内容的页面结构，补充测试样本。
- [ ] 新增素材、平台构建、审核和同步记录的数据表与迁移。
- [ ] 实现 `build`：正文清洗、组件规范化、图片本地化，以及公众号、头条两套 HTML 与 Markdown。
- [ ] 静态化公式（MathJax + resvg）和 Mermaid（可选 Playwright），按输入缓存素材。
- [ ] 实现 `preview`、`review`、`status`，测试改动正文、素材或封面后审核失效。
- [ ] 实现 `sync`、`resolve`，用模拟 CLI 测试预演、成功、明确失败、`unknown` 和重复提交。
- [ ] 使用真实文章和已登录的平台账号验证公众号、头条草稿，确认封面要求和成功输出格式。
- [ ] 更新 Agent Skill，覆盖完整工作流和人工确认步骤。

架构细节见[架构](architecture.md)。
