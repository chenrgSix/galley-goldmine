# Goldmine v0.1 需求

Goldmine 在本地保存 Galley 的公开文章快照，为微信公众号和今日头条生成可审阅的独立版本。用户在平台草稿箱核对后完成正式发布。

## 工作流

1. 初始化本地工作区，检查配置和可用的 Wechatsync CLI。
2. 从 Galley 的公开文章页读取标题、摘要、分类、标签、正文和图片引用。每次发现内容变化时保留版本。
3. 将正文转换为 HTML 和 Markdown。保留公开知识块、提示框、折叠内容和代码，生成 Mermaid 与 KaTeX 的静态图。对无法还原的组件给出明确警告。
4. 保存各平台的文章、封面和素材清单，提供本地预览。将人工审核绑定到平台版本及文章、素材指纹。
5. 逐平台预演并通过外部 Wechatsync CLI 同步已审核草稿。记录确认到的草稿链接及结果。结果不确定时标记为 `unknown`，等待人工核对。

正文和素材按公开页面的内容边界读取。文章中的 HTML 和文字作为输入数据处理。账号会话由浏览器扩展管理，桥接 Token 由环境变量提供。

## 验收

用真实 Galley 公开文章验证正文、代码和必要图片。用已登录的账号分别核对公众号、头条的草稿内容。用本地测试验证失效审核、重复提交、明确失败和不确定结果。当前完成情况见[路线图](roadmap.md)。
